GOLDEN HOUR — an original low-poly 3D open-world crime game set in Porto Lume, a
golden-hour port city. Play Rui Tavares, a wheelman working off a family debt for
fixer Dona Pilar Andrade: lift the package, outrun the PMPL, deliver it. An entry
for the make.fun gta6-01 bounty ("Make GTA 6"). Custom WebGL2 engine, fully
offline and deterministic — the world is generated from a fixed seed.

## Run it

```sh
node main.ts    # generate game/ + screenshots (deterministic, byte-identical)
node serve.ts   # serve game/ at http://localhost:8080
```
